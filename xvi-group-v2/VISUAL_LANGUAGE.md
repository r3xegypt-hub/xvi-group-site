# VISUAL_LANGUAGE.md — XVI GROUP Visual Language System

> Everything must derive from the logo. The diamond mark is the DNA of the entire website.

## ABSOLUTE RULE: NO STOCK PHOTOGRAPHY

**Zero exceptions.** XVI GROUP never uses stock photos. Not now. Not ever.

Only these visual elements are allowed:

| Allowed | Description |
|---------|-------------|
| **Custom SVG** | Hand-crafted vector graphics aligned to brand geometry |
| **Abstract AI illustrations** | Node networks, data flows, cognitive architectures |
| **Architectural geometry** | Lines, frames, grids, diamond patterns |
| **Premium data visualization** | Charts, graphs, metrics — all in brand colors |
| **Typography as visual** | Large headlines, stats, numbers — type IS the visual |

**NEVER:**
- Stock photos of people shaking hands
- Stock photos of "business meetings"
- Stock photos of cityscapes/skylines
- Stock photos of "technology" (circuit boards, code screens)
- Stock photos of AI (robots, brains, neon circuits)
- Any raster image used as a primary visual

**If it can't be expressed with SVG, geometry, typography, or data — it doesn't belong on the site.**

## The XVI Visual Language

### Origin: The Diamond
The diamond mark generates every visual element on the site. From the diamond, we extract:

1. **The Angle** — 60° acute angles become architectural lines
2. **The Intersection** — The diamond's crossing point becomes node networks
3. **The Symmetry** — Perfect bilateral symmetry governs layouts
4. **The Containment** — The diamond's border becomes card frames
5. **The Negative Space** — The space inside the diamond becomes breathing room

### Visual Elements Derived from Logo

#### 1. Executive Geometric Lines
```
─────────────────────────────────────
```
- **Origin:** The diamond's edges, straightened
- **Weight:** 1.5px
- **Color:** Executive Gold (#C9A96E) or Navy (#0A1628)
- **Usage:** Section dividers, hero decoration, meridian line
- **Rule:** Lines are always horizontal or vertical. Never diagonal (except in the logo itself).

#### 2. Architectural Frames
```
┌──────────────────────────────────┐
│                                  │
│                                  │
│                                  │
└──────────────────────────────────┘
```
- **Origin:** The diamond's bounding box
- **Radius:** 12px (cards), 8px (buttons), 0 (sections)
- **Border:** 1px solid rgba(201, 169, 110, 0.12) — subtle gold
- **Usage:** Cards, containers, feature blocks
- **Rule:** Frames always have consistent padding (24px minimum)

#### 3. AI-Inspired Abstract Networks
```
    ◇───────────◇
    │           │
    ◇───────────◇
    │           │
    ◇───────────◇
```
- **Origin:** The diamond's intersection points, connected
- **Style:** Thin lines (1px) connecting diamond-shaped nodes
- **Color:** Navy at 5% opacity (background), Gold at 15% (accent)
- **Usage:** Hero background, technology section, AI illustration
- **Animation:** Subtle pulse on nodes (3s cycle, 0.1 opacity range)
- **Rule:** Maximum 12 nodes per composition. Always symmetrical.

#### 4. Premium Gold Accents
- **Origin:** The meridian line in the logo
- **Usage:** Eyebrow text, active states, CTAs, decorative lines
- **Rule:** Gold never exceeds 5% of viewport. It accents, never dominates.

#### 5. Luxury Glass Surfaces
```
┌──────────────────────────────────┐
│  backdrop-filter: blur(12px)     │
│  background: rgba(255,255,255,0.85)│
│  border: 1px solid rgba(255,255,255,0.5)│
└──────────────────────────────────┘
```
- **Origin:** The transparency of glass — seeing through to what matters
- **Usage:** Navigation on scroll, floating tooltips, overlays
- **Rule:** Maximum 2 glass elements per viewport. Never for cards.

#### 6. Soft Lighting
- **Hero:** Subtle radial gradient from center (#FAFAF8) to edges (#F4F5F7)
- **Sections:** Flat colors with no gradients (except hero)
- **Cards:** Solid white with subtle shadow (no gradient overlays)
- **Rule:** No harsh shadows. No visible light sources. Gallery lighting.

#### 7. Subtle Reflections
- **Glass elements:** Inner shadow (`inset 0 1px 0 rgba(255,255,255,0.6)`)
- **Gold accents:** Slight gradient on hover (light gold to dark gold)
- **Rule:** Reflections are felt, not seen. If the user notices a reflection, it's too much.

### Visual Composition Rules

#### The Rule of Geometry
Every visual composition on the site must contain at least one of:
1. A diamond shape
2. A horizontal line
3. A rectangular frame
4. A node network

If none of these are present, the composition is missing its DNA.

#### The Rule of Symmetry
All layouts maintain bilateral symmetry. The left side mirrors the right (in LTR). In RTL, this reverses.

#### The Rule of Breathing
Every element must have minimum breathing room:
- Between elements: 24px minimum
- Around frames: 24px padding minimum
- Between sections: 96px padding (desktop), 64px (mobile)

#### The Rule of Hierarchy
Visual weight follows this order:
1. Typography (headlines)
2. Gold accents (eyebrows, CTAs)
3. Geometry (diamonds, lines)
4. Cards (white surfaces)
5. Background (light grey)

### Illustration System

#### Style
- **Geometric abstraction** — Never literal, never organic
- **Duochrome** — Navy (#0A1628) + Gold (#C9A96E) only
- **Stroke-only** — No filled shapes except node centers
- **Maximum 7 elements** per illustration
- **SVG format** — Resolution-independent

#### Subject Matter
1. **Networks** — Connected nodes representing organizational structure
2. **Decision Points** — Single nodes with radiating connections
3. **Data Flow** — Lines with directional arrows
4. **Cognitive Architecture** — Overlapping geometric shapes creating emergent patterns

#### Animation
- Draw-in on scroll reveal (stroke-dashoffset, 600ms)
- Subtle pulse on hover (opacity cycle, 3s)
- Never: continuous animation, morphing, particle effects

- Stroke: 0.5px, Gold, opacity 0.15

#### Pattern 02 — Meridian Grid

- Stroke: 0.5px, Gold, opacity 0.1

- Stroke: 0.5px, Navy, opacity 0.05

#### Pattern 04 — Architectural Dot
```
·   ·   ·   ·   ·
  ·   ·   ·   ·
·   ·   ·   ·   ·
```
- Size: 2px diameter
- Color: Gold, opacity 0.2
- Spacing: 24px between dots
- Usage: Card accent, section divider

### Pattern Rules
1. Patterns are always SVG (resolution-independent)
2. Patterns are always subtle (opacity 0.05-0.2)
3. Patterns never compete with content
4. Maximum one pattern per section
5. Patterns can be combined with solid backgrounds
6. Patterns are always tileable (seamless repeat)

### Icon System

#### Style
- **Stroke-only** — No fills except specific indicators
- **Stroke width:** 1.5px
- **Size:** 24px (default), 20px (compact), 32px (large)
- **Color:** Inherit from parent (Navy or Graphite)
- **Corner radius:** Round line caps and joins

#### Icon Categories
1. **Navigation** — Home, Services, About, Industries, Insights, Contact
2. **Action** — Arrow right, Arrow down, External link, Download, Search
3. **Service** — AI, Strategy, Technology, Operations (custom geometric icons)
4. **Social** — LinkedIn, Twitter/X (inline SVG, not icon library)
5. **Interface** — Menu, Close, Language toggle, Theme toggle

#### Icon Rules
1. Icons always have a text label (visible or aria-label)
2. Icons never stand alone without context
3. Icons use the same color as their associated text
4. Maximum 2 icons per card
5. Icons are not decorative — if they don't add meaning, remove them
