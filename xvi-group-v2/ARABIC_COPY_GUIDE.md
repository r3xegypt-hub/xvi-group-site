## 1. ARABIC COPY PHILOSOPHY

The Arabic copy for XVI GROUP is **NOT** a translation of English. It is **original Arabic copy** written by someone who understands:
- Executive business language in Arabic
- Gulf-region corporate communication
- Premium brand voice in Arabic
- The rhythm and formality of Arabic business writing

### Rules
1. **Never translate literally.** Arabic has its own way of saying things.
2. **Use Modern Standard Arabic (MSA).** Not dialect. Not colloquial.
3. **Formal register.** This is a consulting firm, not a tech startup.
4. **Active voice preferred.** But passive is acceptable in formal contexts.
5. **Short sentences.** Arabic readers scan like English readers.
6. **No English words** in Arabic copy (except brand name "XVI GROUP").

## 2. VOICE & TONE

### English Voice
- Confident but not arrogant
- Technical but accessible
- Premium but not pretentious
- Direct but not blunt

### Arabic Voice (Equivalent, Not Identical)
- **واثق而不 متعالي** — Confident without arrogance
- **مهني而不 تقني أكثر من اللازم** — Professional without being overly technical
- **فاخر而不 متكلّف** — Premium without being affected
- **مباشر而不 حاد** — Direct without being harsh

### Arabic Tone Examples

| English | ❌ Literal Arabic | ✅ Executive Arabic |
|---------|------------------|-------------------|
| "Start a Conversation" | "ابدأ محادثة" | "نبدأ الحوار" |
| "View Our Work" | "شاهد أعمالنا" | "استعرض م portfolio" |
| "Let's Build Something Extraordinary" | "دعنا نبني شيئاً استثنائياً" | "معاً نحو إنجاز استثنائي" |
| "Ready to transform your enterprise?" | "هل أنت مستعد لتحويل مؤسستك؟" | "هل تسعى لنقلة نوعية في مؤسستك؟" |

## 5. ARABIC NUMBERS & DATES

### Number System
| Western | Arabic-Indic | Usage |
|---------|-------------|-------|
| 0 | ٠ | |
| 1 | ١ | |
| 2 | ٢ | |
| 3 | ٣ | |
| 4 | ٤ | |
| 5 | ٥ | |
| 6 | ٦ | |
| 7 | ٧ | |
| 8 | ٨ | |
| 9 | ٩ | |

### Rules
- **Stat numbers:** Use Western numerals (200+, 98%, 24/7) — Arabic readers expect this in business context
- **Dates:** Use Arabic-Indic (٢٠٢٥) in formal contexts
- **Phone numbers:** Western (+971 2 XXX XXXX)
- **Percentages:** 98% (Western)
- **Currency:** د.إ (Arabic), AED (English)

## 6. RTL TYPOGRAPHY RULES

### Text Alignment
- All body text: **right-aligned**
- All headings: **right-aligned**
- All labels: **right-aligned**
- Centered text: Only for decorative/overline elements

### Punctuation
| Symbol | English | Arabic |
|--------|---------|--------|
| Period | . | . (same) |
| Comma | , | ، (Arabic comma) |
| Question mark | ? | ؟ (reversed) |
| Semicolon | ; | ؛ (reversed) |
| Quotation | " " | « » (guillemets) or " " |
| Colon | : | : (same) |
| Dash | — | — (same) |

### Mixed Content
When Arabic and English appear together:
1. Numbers stay Western (200+, 98%)
2. Brand name stays English (XVI GROUP)
3. Technical terms stay English if no standard Arabic equivalent
4. Punctuation follows the dominant language

## 7. COMMON MISTAKES TO AVOID

| ❌ Mistake | ✅ Correct |
|-----------|-----------|
| "المجموعة السادسة عشر" (literal translation of XVI GROUP) | "XVI GROUP" (keep brand name) |
| "ابدأ محادثة" (literal "start a conversation") | "نبدأ الحوار" (executive "let's begin the dialogue") |
| "شاهد أعمالنا" (literal "view our work") | "استعرض مشاريعنا" (professional "review our projects") |
| Using Western punctuation in Arabic text | Use Arabic punctuation (، ؟ ؛) |
| Right-to-left numbers | Keep numbers LTR within RTL text |
| Mixing Arabic and English fonts | Never mix — each language uses its own |
| Using "أنت" (informal you) | Use "أنتم" (formal you) or restructure |
